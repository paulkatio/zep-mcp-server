> **Wichtig:** `employees` werden per **`username`** angesprochen (z. B. `max.mustermann`),
> `customers` per **`customer_number`** (z. B. `K-12345`) — **nicht** über die numerische
> interne ID. Falscher Identifier-Typ → 404 beim ersten Versuch.
